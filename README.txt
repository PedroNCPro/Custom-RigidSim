INSTRUCTIONS

- Run the finalProject binary file or build the execution file again first using:

cmake -B build
make -C build

- You are free to easily change the objects displayed, their attributes, etc. in the configScene() function inside config.cpp. The explanation of the functions can be found in the tables of the project report file "IG03___Final_Project_Report.pdf".

COMMANDS

> Help:
    Mouse commands:
    * Left button: rotate camera
    * Middle button: zoom
    * Right button: pan camera
    Keyboard commands:
    * H: print this help
    * P: toggle simulation
    * R: reset simulation
    * S: save a screenshot
    * W: wireframe rendering
    * F: surface rendering
    * L: apply one step of Loop subdivision to the central mesh
    * ESC: quit the program
